# Luma & Lace

An original event-styling website concept by NexWeb AI Studios. The brand, event scenes, and service presentation are fictional. No real event portfolio or booking service is represented.

Run `npm install`, then `npm run dev`; verify a production build with `npm run build`. The seven images in `public/images` were generated for this project and are not photographs of completed events.

The quote builder demonstrates an itemized event brief and opens a WhatsApp conversation with NexWeb AI Studios. It does not publish event prices, make bookings, or send enquiries to an events company. Instagram and Facebook links point only to the platforms' home pages.
