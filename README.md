# Majestic Parties & Events

One-page React + TypeScript site. Run `npm install`, then `npm run dev`; verify a production build with `npm run build`.

The images in `public/images` were downloaded from the business's public Instagram and Facebook posts on 7 October 2026. Each gallery image links to its original post. The site is a sales concept; confirm image reuse rights with Majestic before public launch.

The quote builder gathers requirements and sends an itemized WhatsApp enquiry. It does not publish prices because no current Majestic price list was available.
